# Contributing

Thank you for your interest in contributing!

## How to Contribute
1. Fork the repository
2. Create a feature branch
3. Make your changes (code, docs, or tests)
4. Add or update tests for new/changed functionality
5. Run the test suite: `make test`
6. Commit with a clear message (see commit style in repo)
7. Push to your fork and submit a pull request

## Guidelines
- Follow code style and typing guidelines (see code and pyproject.toml)
- Document new functions/classes (numpy docstring style for Python)
- Add tests for all new features and bugfixes
- Keep PRs focused and well-described
- For major changes, open an issue or discussion first

## Code of Conduct
Be respectful and constructive. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) if present.
