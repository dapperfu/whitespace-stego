🔐 Whitespace Steganography

Hide messages in plain sight using invisible Unicode characters

ℹ️ How it works:

  • Encode: Hide your secret message within normal-looking text
  • Decode: Extract hidden messages from text that contains encoded data
  • Password Protection: Optionally encrypt your messages with a password
  • File Upload: Upload files for decoding or use text input
  • Download: Save encoded text to a file
  • Invisible: Uses zero-width Unicode characters that are invisible to the human eye
Note: Password encryption is not yet supported in the WebAssembly version. Use Python, Rust, or C implementations for password protection.
