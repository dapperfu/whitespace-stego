## 🧪 What is this?

`whitespace-stego` is a toolkit for exploring the limits of hiding data in plain sight using **invisible Unicode whitespace characters** — such as zero-width space, non-breaking space, and other sneaky glyphs. It’s not just about functionality. It’s an *artful* exercise in **Vibe Coding**: letting intuition, rhythm, and divergent thought guide implementation.
