# whitespace-stego-cpp

This is the C++ implementation of the whitespace steganography tool. It is designed with heavy use of object-oriented programming (OOP) principles. The implementation aims to produce output identical to the C, Go, Python, and Rust versions.

## Binary Name
- `whitespace-stego-cpp`

## Folder Structure
- `include/` — C++ header files
- `src/` — C++ source files
- `bin/` — Compiled binaries
- `test/` — Unit and integration tests

## OOP Design
- **Message**: Class for encoding, decoding, encrypting, and decrypting messages
- **Carrier**: Class for handling carrier text
- **Encoder/Decoder**: Classes for encoding/decoding logic
- **Crypto**: Class for encryption/decryption
- **Utils**: Utility functions

## Build
A `Makefile` will be provided for building and testing the project.

## Compatibility
- Output is designed to be identical to the other implementations.
